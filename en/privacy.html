Privacy by default

Your study records stay in your browser.

The project is static, has no user account and no project backend receiving journal entries or assessments.

Local data

Tools use localStorage for journal entries, scenarios, replays, learning progress and local certificates.

Offline cache

The PWA caches public site files and previously visited pages. It does not copy localStorage records into the cache.

Backups

The Data Manager exports a JSON file controlled by you. Treat that file as private because it can contain personal notes.

Deletion

You can delete project data from the Data Manager or from your browser's site-data settings.

No project analytics: the code does not add its own analytics or telemetry.
