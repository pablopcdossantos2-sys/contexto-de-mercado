Início / Privacidade
Privacidade por padrão

Seus registros ficam no seu navegador.

O projeto é estático, sem conta de usuário e sem backend próprio para receber Diário, cenários ou avaliações.

O que é armazenado

As ferramentas usam localStorage para guardar checklist, Diário de Contexto, tentativas do Laboratório, revisões Plano x Mercado Real, Replays, progresso de aprendizagem e certificados locais.

O que não é enviado pelo projeto

Esses registros não são enviados para um servidor próprio do Contexto de Mercado. O código não inclui conta, telemetria ou analytics próprios.

Imagens do Replay

As imagens selecionadas no Replay de Contexto são usadas na sessão do navegador para visualização. O histórico dessa ferramenta persiste apenas o texto; as imagens não são salvas no localStorage pelo projeto.

PWA e cache offline

O Service Worker guarda arquivos públicos do site — HTML, CSS, JavaScript e páginas já visitadas — para permitir uso offline. Ele não copia o conteúdo do localStorage para o cache.

Backup e portabilidade

A página Gerenciar dados permite exportar um JSON com todos os conjuntos locais e importá-lo em outro navegador. Esse arquivo pode conter anotações pessoais; trate-o como um arquivo privado.

Como apagar

Use “Apagar todos os dados do projeto” em Gerenciar dados. Também é possível limpar os dados do site nas configurações do navegador. A exclusão local não pode ser desfeita sem um backup.

Dados de terceiros

Se o site for hospedado no GitHub Pages, a própria infraestrutura de hospedagem pode processar dados técnicos de acesso de acordo com as políticas do provedor. Este projeto não adiciona rastreamento próprio sobre esses acessos.

Resumo: dados pessoais de estudo ficam locais por padrão; backup é controlado pelo usuário; o PWA armazena arquivos do aplicativo, não o conteúdo do Diário.
