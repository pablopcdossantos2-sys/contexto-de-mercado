# Contexto de Mercado

Web portfólio educacional dedicado a ensinar traders iniciantes a compreenderem o **contexto de mercado antes de executar operações**.

O projeto combina:

- artigos didáticos sobre leitura de contexto;
- uma rotina pré-mercado estruturada;
- ferramentas interativas para transformar análise em hábito;
- exercícios de construção de cenários;
- princípios de gestão de risco e tomada de decisão.

## Objetivo

A proposta não é fornecer sinais de compra ou venda. O objetivo é ensinar o usuário a responder, antes de operar:

1. **Que tipo de mercado estou vendo?**
2. **Onde o preço está dentro da estrutura?**
3. **Quais fatores podem alterar o comportamento do ativo hoje?**
4. **Quais cenários são plausíveis?**
5. **O que precisa acontecer para que uma operação faça sentido?**
6. **Em que situações é melhor não operar?**

## Estrutura inicial

- `index.html` — página inicial e trilha de estudo.
- `artigos/` — artigos educacionais.
- `rotina/` — rotina pré-mercado guiada.
- `ferramentas/` — ferramentas práticas.
- `styles.css` — identidade visual e responsividade.
- `script.js` — navegação e recursos compartilhados.

## GitHub Pages

O site foi desenvolvido como projeto estático, sem backend e sem dependências externas obrigatórias, para funcionar diretamente pelo GitHub Pages ou localmente abrindo o arquivo `index.html`.

## Aviso educacional

Todo o conteúdo tem finalidade exclusivamente educacional. Nada neste projeto constitui recomendação de investimento, promessa de resultado ou sinal operacional. Trading envolve risco de perda financeira.
