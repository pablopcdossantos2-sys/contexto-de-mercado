Privacidad por defecto

Tus registros de estudio permanecen en tu navegador.

El proyecto es estático, no tiene cuenta de usuario ni backend propio que reciba diarios o evaluaciones.

Datos locales

Las herramientas usan localStorage para diario, escenarios, replays, progreso de aprendizaje y certificados locales.

Caché offline

La PWA guarda archivos públicos del sitio y páginas visitadas. No copia los registros de localStorage al caché.

Backups

El Gestor de Datos exporta un JSON controlado por ti. Trátalo como archivo privado porque puede contener notas personales.

Borrado

Puedes borrar los datos del proyecto desde el Gestor de Datos o desde la configuración de datos del navegador.

Sin analytics propios: el código no agrega telemetría ni analytics del proyecto.
