# Market Context

[Português](README.md) · **English** · [Español](README.es.md)

An open educational web project designed to help beginner traders understand **market context before executing trades**.

The project combines conceptual education, a pre-market routine, local records, deliberate practice, replay exercises, learning paths and process metrics.

## Core principle

**Context is not prediction.**

The project teaches users to observe regime, location, volatility, timing, references, flow and events; build conditional scenarios; define invalidation; and review reading quality separately from financial outcome.

## Current structure

- 10 core context modules;
- seven-step pre-market routine;
- context checklist;
- context journal;
- scenario laboratory;
- Plan vs. Real Market review;
- context replay and guided replay;
- beginner, intraday and order-flow learning paths;
- quizzes and exercises;
- local educational certificates;
- process dashboard;
- full local-data backup/import;
- PWA/offline support;
- accessibility and mobile safeguards;
- Portuguese, English and Spanish portals.

## English version

Open `en/index.html` for the English portal. It includes the consolidated core course, pre-market routine, tool catalog and privacy information.

Interactive tools share the canonical implementation and the same local data store so records remain portable between language portals.

## Privacy

Study records are stored in the browser by default. The project has no user account and no project backend receiving journal entries. The PWA caches public application files, not the content of localStorage.

## Disclaimer

Educational content only. Nothing in this project is investment advice, a trading signal, a performance promise or evidence of statistical edge.
